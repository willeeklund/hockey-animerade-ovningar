# Egna träningspass

JSON-filerna här byggs in i appen och visas under *Inbyggda pass – Egna pass* i panelen Träningspass. Varje fil är ett träningspass i samma format som när man exporterar ett pass från appen (Träningspass → Exportera).

Lägg till ett pass genom att exportera det från appen, eller avkoda en delningslänk, och spara filen här. Filnamnet blir passets adress, till exempel `#!/pass/egna/zonspel-1-mot-1`. Starta om `npm run dev` efter att en ny fil har lagts till.

| Fil | Pass |
|---|---|
| zonspel-1-mot-1.json | 1 mot 1 med angling: zonspel 1 mot 1, först rakt på mål och sedan med angling |
